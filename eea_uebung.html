Lineare Gleichungen in ℤ/nℤ

Löse die Gleichung im Restklassenring. Gesucht ist ein Repräsentant aus {0, …, n−1}. Beachte:
  • Wenn der Koeffizient vor dem x ein multiplikatives Inverses in ℤ/nℤ hat, gibt es immer genau eine Lösung.
  • Wenn der Koeffizient kein multiplikatives Inverses in ℤ/nℤ hat, kann es passieren, dass es keine Lösung gibt. In diesem Fall kann es aber auch eine oder mehrere Lösungen geben. Die Aufgaben werden so generiert, dass dies nur für kleine Werte von n der Fall. Ob es eine Lösung gibt, kann man dann einfach durch Probieren herausfinden.
