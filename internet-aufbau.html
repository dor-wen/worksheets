Aufbau und Funktionsweise des Internets

🌍 Was ist das Internet?

Das Internet ist ein riesiger Verbund von Computern auf der ganzen Welt. Die meisten Geräte sind dabei per Kabel miteinander verbunden - z.B. Seekabel auf dem Meeresboden.

Stell dir das Internet als „Netzwerk von Netzwerken“ vor: Zu Hause hast du ein kleines Netzwerk (dein WLAN), in der Schule ein größeres – und all diese Netzwerke sind weltweit miteinander verbunden. Deshalb heißt es auch Inter-net: das Netz zwischen den Netzen.

Wichtige Gerätetypen im Internet

📱 Privatgeräte – die Geräte von uns allen

Privatgeräte sind die Geräte, die wir täglich benutzen: Computer, Laptops, Smartphones, Tablets, Drucker oder Smart-TVs. Sie sind meistens nur zeitweise eingeschaltet und verbinden sich über WLAN oder Kabel mit dem Internet.

Anders als ein Server stellen Privatgeräte meist keine Inhalte für alle bereit. Stattdessen fragen sie Inhalte bei Servern ab – zum Beispiel eine Webseite, ein Video oder eine Nachricht.

🖥️ Server – die Computer, die etwas bereitstellen

Ein Server ist ein Computer, der rund um die Uhr eingeschaltet ist und anderen Computern etwas zur Verfügung stellt – zum Beispiel Webseiten, Videos oder E-Mails. Wenn du eine Webseite aufrufst, holst du sie dir von einem solchen Server.

🧭 Router – die Wegweiser im Netzwerk

Ein Router sorgt dafür, dass Daten den richtigen Weg finden. Stell dir einen Router wie eine Wegkreuzung vor: Datenpakete kommen an und der Router entscheidet, wohin sie als Nächstes müssen, damit sie ihr Ziel erreichen. Zu Hause verbindet dein Router außerdem all deine Geräte mit dem Internet.

📮 Was ist eine IP-Adresse?

Jedes Gerät (Computer, Handy, Drucker), das direkt mit dem Internet verbunden ist, hat eine eigene IP-Adresse. Man kann sie sich wie eine normale Adresse vorstellen. Wenn ein Gerät einem anderen Gerät ein Informationspaket schicken möchte, dann muss der Sender die (IP-)Adresse des Empfängers kennen.

Eine IPv4-Adresse besteht aus vier Zahlenblöcken (genannt Oktette), getrennt durch Punkte. Jeder Block ist eine Zahl von 0 bis 255.
✅ Beispiel: 192.168.0.1

🔍 Was ist DNS?

Wenn ein Gerät S ein Paket über das Internet an ein Gerät E senden möchte, dann muss S die IP-Adresse von E kennen. Zum Beispiel könnte dein Smartphone das Gerät S sein, das dem Web-Server E die folgende Nachricht schickt: Sende mir die Hauptseite von www.youtube.com.
Ziemlich sicher kennst du aber nicht die IP-Adresse des Web-Servers, auf dem der Inhalt für www.youtube.com gespeichert ist. Und dein Smartphone kennt sie zunächst auch nicht. Genau dafür gibt es das (Domain Name System) (DNS). Es übersetzt Domain-Namen in die zugehörige IP-Adresse.

Ablauf kurz erklärt: Du gibst www.ard.de ein → dein Gerät fragt einen DNS-Server nach der passenden IP-Adresse → der DNS-Server antwortet z. B. 23.218.170.172 → dein Gerät ruft die Webseite über diese IP-Adresse ab.

    🧱 Webseiten sind nur Text

    Eine Webseite ist im Grunde reiner Text – erst der Browser macht daraus eine schöne, bunte Seite mit Überschriften, Bildern und Links. Der Text enthält dafür kleine Befehle, die in spitze Klammern geschrieben werden, z. B. <h1>.

    Du siehst den Text mit den Befehlen – der Browser zeigt das Ergebnis. Probiere es unten selbst aus: Ändere den Text im linken Feld und schaue, was rechts passiert!

    Bausteine von Webseiten

    Überschrift: <h1>Titel</h1> – große Überschrift (<h2>, <h3> werden kleiner)

    <h1>Meine erste Webseite</h1>

    Text (Absatz): <p>Beliebiger Text</p>

    <p>Das ist ein einfacher Absatz.</p>

    Link: <a href="ADRESSE">Anzeigetext</a> – href enthält die Ziel-URL

    <a href="https://www.ard.de">Zur ARD</a>

    Bild: <img src="BILD-ADRESSE" alt="Beschreibung"> – src enthält die Adresse des Bildes

    <img src="https://picsum.photos/300/150" alt="Zufallsbild">

    💾 Weiter experimentieren: Deine eigene Webseite auf dem PC

    Jetzt wird es spannend: Du erstellst eine echte Webseite als Datei auf deinem eigenen Computer. Dafür brauchst du zwei Dateien im selben Ordner: eine HTML-Datei (der Inhalt) und eine CSS-Datei (das Aussehen).

    1. Erstelle auf deinem PC einen neuen Ordner, z. B. meine-webseite auf dem Desktop.
    2. Öffne einen einfachen Texteditor (z. B. den Editor von Windows oder Notepad++). Nicht Word verwenden!
    3. Erstelle eine Datei namens index.html, kopiere den folgenden Text hinein und speichere sie in deinem Ordner.
    4. Erstelle eine zweite Datei namens styles.css, kopiere den CSS-Text hinein und speichere sie ebenfalls im Ordner.
    5. Öffne die Datei index.html mit einem Doppelklick – sie wird im Browser angezeigt.
    6. Ändere Texte und Farben, speichere und lade die Seite im Browser neu (F5). So siehst du sofort, was sich geändert hat!

    📄 Datei 1: index.html

    <!DOCTYPE html>
<html lang="de">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Meine Webseite</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>

  <header>
    <h1>🙂 Meine Webseite</h1>
    <nav>
      <a href="#ueber-mich">Über mich</a>
      <a href="#links">Lieblings-Links</a>
      <a href="#bild">Bild</a>
    </nav>
  </header>

  <main>
    <section id="ueber-mich" class="karte">
      <h2>Über mich</h2>
      <p>Hier steht bald etwas über mich – Name, Klasse, Hobbys ...</p>
    </section>

    <section id="links" class="karte">
      <h2>Meine Lieblings-Links</h2>
      <ul>
        <li><a href="https://www.ard.de" target="_blank">ARD</a></li>
        <li><a href="https://de.wikipedia.org" target="_blank">Wikipedia</a></li>
        <li><a href="https://www.leifiphysik.de" target="_blank">Leifi Physik</a></li>
      </ul>
    </section>

    <section id="bild" class="karte">
      <h2>Ein Bild</h2>
      <img src="https://picsum.photos/400/200" alt="Zufallsbild">
      <p class="bildtext">Das Bild kommt von picsum.photos.</p>
    </section>
  </main>

  <footer>
    <p>Erstellt mit HTML und CSS – viel Spaß beim Ausprobieren!</p>
  </footer>

</body>
</html>
